# 知行（Zhixing）

Android-first、本機優先的個人 AI 工作台。

知行支援多模型服務、串流與多模態對話、訊息分支、助手、MCP、搜尋、語音、本機工作區，以及透過自有 Wire 端對端加密中繼繼續遠端 Codex 專案與歷史 Thread。模型請求預設由裝置或開發機直接傳送至使用者設定或登入的服務，不接入第三方遙測、更新來源或免費模型服務。
