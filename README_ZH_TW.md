# 知行（Zhixing）

Android-first、本機優先的個人 AI 工作台。

知行支援多模型服務、串流與多模態對話、訊息分支、助手、MCP、搜尋、語音、本機工作區，以及在同一聊天產品內切換 Chat 與 Work。0.2.2 的 Codex 能力仍透過自有 Wire 中繼交付；後續 Work 目標態以程式庫為分組，經 Tailscale WSS 直連開發機 Codex App Server。模型請求預設由裝置或開發機直接傳送至使用者設定或登入的服務，不接入第三方遙測、更新來源或免費模型服務。
