# 模块：release-notes

记录知行各版本的功能变更、修复与升级指引，供用户与开发者查阅。  
模块按版本号组织为独立 Markdown 文件，每新增版本即手动添加对应文档，无运行时数据流。控制流由发布流程触发，文件内容以静态文本形式被应用内更新日志或帮助页面直接引用。对外接口为直接读取，无其他模块依赖。  

修改指引：新增版本时，在 `release-notes/` 下创建如 `0.4.0.md` 文件，参照现有模板编写发布说明。
