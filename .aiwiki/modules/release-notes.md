# 模块：release-notes

记录知行各版本的新特性、修复与升级指引。

模块按语义化版本号组织，每个文件对应一个版本的发布说明，包含核心变更、修复项与升级步骤。内容面向用户和开发者，帮助理解版本演变与操作要求。无外部逻辑依赖，仅作为静态文档消费。

修改指引：新增版本时，按现有模板在对应路径创建 `x.y.z.md` 文件，描述特性、修复与升级信息。

## 文件摘要
