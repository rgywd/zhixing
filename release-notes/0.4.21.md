# 知行 v0.4.21

- 主聊天可按你的要求修改自己的名称、提示词和配置，也可创建、配置和委派子智能体；设置页与聊天共享同一份配置。
- 提示词和子智能体配置通过普通文件读写与精确编辑管理；自己的提示词在当前对话下一轮生效，无需新建聊天。
- 子任务使用独立上下文，支持进度查询、停止、继续、失败恢复，以及向你提问后接续原任务。
- 修复 DeepSeek 在说明文字与工具调用同时返回时的消息续接错误，完善版本冲突、必需参数和配置生效提示。
- 保留独立 Work 应用与同签名配置导入能力。本版不包含账单识别扩展、递归委派或后台定时执行。

## 安装与升级

- 覆盖安装 Chat 与 Work 对应的 Universal APK，保留原有数据；两个应用的包名和数据继续独立。
- 主助手按请求管理子助手的模型及能力；新增模型凭据仍需在设置中配置。
- 已开始的任务保持原配置快照；应用重启后中断任务需明确重试，不会自动重放外部操作。

已完成单元测试、设备回归及 DeepSeek Flash / V4 Pro 非流式真实流程验收；真实模型测试是小样本，不代表所有模型与任务均有相同表现。
