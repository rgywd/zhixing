# 知行 0.3.9

0.3.9 完成正式安装包向公开发行仓的迁移，并新增真实可用的本地待办与弱日历，同时修复火山引擎
Agent Plan 语音协议。

## 待办与弱日历

- 右侧生活概览不再展示硬编码事项，改为 Room 持久化的真实本地待办。
- 支持新增、编辑、完成、恢复、删除与本地通知提醒；过期提醒不会被保存或重新调度。
- 可选读取未来 7 天系统日历并与待办混排；拒绝日历权限不影响本地待办。
- 普通聊天新增待办查询、创建、修改、完成和删除工具，所有写操作仍需用户确认。
- 数据库从 37 升级到 38，只新增待办表与索引，不清理既有数据。

## 火山引擎 Agent Plan 语音

- 修复 Agent Plan ASR，改用套餐要求的异步大模型语音识别 WebSocket 端点与资源标识。
- 修复 Agent Plan TTS，改用单向流式 WebSocket 协议、`seed-tts-2.0` 与套餐内置音色。
- 仅迁移知行旧内置默认值；用户自定义的端点、资源、模型与音色保持不变。

## 发布与更新

- 正式 APK、对应源码、更新清单和校验和只发布到公开仓库 `rgywd/zhixing-releases`。
- 正式客户端的更新地址固定为公开发行仓的 `latest.json`；staging 客户端继续禁用正式更新检查。
- 0.3.9 是首个内置公开更新源的版本。0.3.8 及更早版本需要手动安装一次 0.3.9，之后即可继续在应用内更新。
- Release 只提供一个 `zhixing-0.3.9-universal.apk`，同时支持 arm64-v8a 真机和 x86_64 测试环境。
