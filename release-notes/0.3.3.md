# 知行 0.3.3

0.3.3 让用户画像从手工维护升级为可调度的增量维护，同时加入火山引擎 Agent Plan 语音合成，并修复 Work 长会话打开后停留在旧消息顶部的问题。

## 自动维护用户画像

- 使用设置中的快速模型，从最近对话提取并维护四维用户画像。
- 默认每 6 小时增量运行一次，支持启动补跑和手动触发。
- 记忆设置中可以调整开关、维护间隔、应用策略、证据数量和单次处理上限。
- 用户手工维护的画像保持锁定；模型生成的候选可以自动应用或等待确认。

## 火山引擎语音合成

- 语音设置新增独立的“火山引擎”TTS 提供商。
- 默认使用 `seed-tts-2.0`、小何 2.0 音色和方舟 Agent Plan V3 单向流式 WebSocket 接口。
- 可以选择 Vivi、云舟、小天或填写其他 Speaker ID。
- 协议错误、失败事件、文本帧和连接提前关闭会显示明确错误，不会把不完整音频视为成功。

## Work 会话体验

- 打开已有 Work 会话时直接定位到最下面的最新进展，不再先显示顶部的早期消息。
- 会话运行中追加新事件时继续平滑跟随最新内容。

## 升级说明

- 可从 0.3.2 直接覆盖升级到 0.3.3。
- 自动画像维护默认使用已有快速模型配置；启用前请确认快速模型可用。
- 火山引擎 TTS 需要用户自行填写有效的 Agent Plan API Key。
