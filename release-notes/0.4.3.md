# 知行 0.4.3

0.4.3 让右侧“现在”面板更自然地接入普通聊天，同时收紧画像并发写入，修复 Work 提问链路在新版本
Node.js 下的兼容问题。

## 从当前状态继续聊

- 当前状态卡新增“聊聊”，会在当前助手下新建普通 Chat，并预填发送前可编辑的状态上下文。
- 草稿带有状态记录、可讨论依据和相关画像记忆的引用，方便继续追问或纠正长期信息。
- 被隐私设置排除的身体等依据不会进入聊天草稿；旧状态缺少隐私白名单时也默认不带入相关内容。

## 交互与记忆更稳定

- 右侧事项抽屉跟随手势展开和收起，拖动过程更连贯。
- 自动画像维护改为全局串行；并发触发时不再反复生成相似摘要，同一维度的历史重复项会收敛到一条有效画像。
- 修复 Android 26–33 上知识空间路径校验可能不可用的兼容问题。

## Work 兼容性

- 修复 Work 的 `ask` 在 Node.js 24.18 环境中可能立即超时的问题，等待用户回答的链路恢复正常。
