# 知行 0.4.12

0.4.12 收紧了失败任务和长期记忆写入的收尾行为，解决 Today 重试卡长期堆积以及记忆写入失败后无法可靠纠正的问题。

## 失败任务与 Today

- 失败任务只在 24 小时内保留为可重试项，过期后不再持续出现在 Today；也可以选择“不再重试”立即关闭。
- 重试会回到原始消息及对应对话分支，不再错误地从会话末尾重新执行。
- 同一来源发起新尝试后会替换旧失败项，删除来源对话时也会同步清理关联的任务运行记录。

## 长期记忆写入

- 记忆写入改为显式区分追加、替换、删除和无需变更，并按具体操作校验必需参数。
- 参数或执行失败时返回可纠正的结构化结果，模型可以修正后重试；只有成功写入或明确无需变更才结束本轮记忆处理。
- 空内容、无效来源和不完整操作会在执行前被拦截，错误提示会保留具体原因。

## 数据升级

- 数据库由 schema 45 升级到 46，并一次性清理旧版本遗留的助手任务运行记录、事件和软链接。
- 实际聊天、Agenda 事项、长期记忆、已产生结果和 Work 运行上下文不会因本次清理而删除。
