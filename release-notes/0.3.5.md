# 知行 0.3.5

0.3.5 在 0.3.4 的 Work 基础对话体验之上，进一步补齐目录发现、会话辨认、结果提醒和任务收口，并重构长期用户画像的可信准入链路。

## Work 发起与辨认

- Runner 可以从显式授权的目录根自动发现本机项目，新建 Work 会话时不再要求逐个维护固定仓库。
- 新会话会使用已配置的快速模型生成简短标题，并在模型不可用、生成失败或纯图片输入时回退到首条消息摘要或仓库名。
- 标题会持久化到 Work Core 与本机缓存；旧客户端和已有会话仍可继续使用。

## Work 完成提醒与可靠收口

- 多个任务并行时，某个任务完成、结束或失败后，常驻置顶通知会镜像最近关键结果 60 秒，同时保留剩余任务数；点击可直接进入对应会话。
- Runner 现在根据 Codex 的 `turn.completed` / `turn.failed` 语义事件结束本轮，并在 CLI 未及时退出时清理进程树，减少任务实际完成但手机端一直显示运行中的情况。
- 终态与消息继续通过本地 outbox 排序提交，断网或 Runner 重启后可以重放。

## 长期用户画像 V2

- 自动画像先保存带用户原话证据的内部观察，再通过独立对话数、时间跨度和本地确定性评分决定是否晋升，降低单次聊天和模型自报造成的误画像。
- 内置画像维度各自只维护一条规范摘要；内部观察不进入提示词，只有通过准入且处于活跃状态的画像会参与对话。
- 画像管理页支持分页查看，并能追溯支撑观察与原话证据；用户编辑、确认或归档后，后台维护不会覆盖。

## 普通聊天与事项入口

- 空知识空间不再注册知识工具或注入检索提醒，普通对话不会因为空库受到干扰。
- 会话页新增右侧“事项”侧栏界面与筛选、状态卡片，为后续任务和日历闭环铺设入口；本版本尚未接入真实事项数据、持久化和详情管理。

## 升级说明

- 可从 0.3.4 直接覆盖升级到 0.3.5。
- Room 会自动执行 35 → 36 → 37 迁移：长期画像 V2 会清理旧版 `PROFILE` 并保留普通 `CONTEXT` 记忆，Work 旧会话标题会以仓库名回填。
- 要使用目录自动发现、会话标题和可靠终态收口，请同时升级到本版本对应的 Work Core 与 Runner；协议新增字段保持向后兼容。
