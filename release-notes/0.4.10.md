# 知行 0.4.10

0.4.10 重做了长期记忆的保存与使用方式，并修正 Agenda 任务在聊天和 Today 中暴露内部信息的问题。

## 长期记忆

- 长期记忆改为带版本和来源的 Markdown 文档，个人信息与偏好保持精简可见，其他主题按需读取。
- 取消后台静默整理画像；记忆的新增、修改和删除改为对话中可见的工具操作，用户可以明确知道发生了什么。
- 长期记忆与原始聊天检索保持分离，升级时保留兼容迁移和数据恢复边界。

## Agenda 与 Today

- Agenda 创建、更新、完成或删除后的回复改为自然语言，不再向用户展示 UUID、状态枚举和来源枚举。
- Today 完成卡使用真实事项标题，不再直接把原始提问当作任务名称。
- 从聊天创建的事项会在编辑页标明“来自聊天”，并可返回原对话继续调整。
- 修正历史 Agenda 结果覆盖后续回复以及多工具结果丢失的边缘情况。
