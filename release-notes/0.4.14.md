# 知行 0.4.14

0.4.14 让普通聊天更自然地使用实时生活信息和长期记忆，并提高 Work 会话冷启动时的稳定性。

## 记忆改为前台按需维护

- 普通聊天只在问题确实依赖长期信息时读取记忆，不再为了完成每一轮回答强制检查记忆。
- 只有出现值得长期保留的新事实或偏好时才写入记忆；没有变化时不再产生可见的 `no_change` 工具调用。
- 用户手动编辑、来源引用、作用域与并发版本保护保持不变，记忆仍在当前 App 会话中实时生效。

## 实时生活上下文

- 普通聊天可以在相关问题中按需读取本地时间与时区、区县级位置和天气，以及待办与长期计划摘要。
- 开启“允许 AI 使用身体数据”后，还可使用最近的睡眠、心率、血氧、步数、卡路里和运动次数。
- 工具保持只读，不返回坐标、街道或原始传感器历史；权限不足或数据过期时会明确降级，不猜测缺失信息。

## Work 冷启动恢复

- Codex App Server 的初始化使用独立超时预算，首次冷启动超时会清理失败进程并自动重试一次。
- thread、turn 启动与普通控制请求使用不同超时，降低开发机刚上线或安全软件扫描时的误失败。
- 每个 turn 结束后仍会退出 App Server 并释放进程内存；保留可继续的会话不需要点击“结束对话”。

## 发布工程

- 日常 Work 与 Android 重门禁迁到开发机执行，GitHub PR 只保留轻量策略检查。
- 正式标签仍执行完整云端测试、签名 APK 构建、源码归档、校验和与公开发布门禁。

## 数据升级

- 数据库 schema 保持 48，本版不新增数据迁移，也不改变正式包名、签名或数据库身份。
- 现有聊天、记忆、Work 会话、Agenda、长期计划和知识库数据会原样保留。
