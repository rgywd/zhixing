# 知行 0.3.4

0.3.4 集中完善 Work 移动端的基础对话体验，让远程开发会话具备普通聊天应有的消息操作、草稿保护和历史阅读能力。

## Work 消息操作

- 用户和 AI 的文本消息均可选择文字、复制全文或引用到输入框。
- 用户消息可以载入输入框修改后重新发送，不改写已经执行的历史记录。
- Markdown 与代码块继续复用原有聊天渲染和复制能力。

## 草稿与失败恢复

- 输入内容按 Work 会话保存在本机，切换页面后仍可继续编辑。
- 只有消息被服务端成功接收后才会清除草稿。
- 发送失败时保留正文和附件，并提供原地重试入口。

## 历史阅读体验

- 打开会话时仍会定位到最新进展。
- 用户上滑查看历史时，新消息不会强制把页面拉回底部。
- 页面会累计新消息数量，并提供主动跳转到最新内容的入口。

## 升级说明

- 可从 0.3.3 直接覆盖升级到 0.3.4。
- 本版本不改变 Work Core 协议和已有会话数据结构。
