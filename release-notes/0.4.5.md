# 知行 0.4.5

0.4.5 聚焦聊天安全变量、Codex Work 模型配置和长对话压缩，让开发协作与持续会话更可靠。

## 聊天安全变量

- Workspace 普通聊天支持在消息开头声明临时变量和加密用户变量，便于向本机工具安全传递 API Key 等敏感值。
- 变量声明在发送前会被移除，普通聊天记录、模型请求、工具参数和导出内容只保留变量名与操作结果。
- 工具输出会按实际变量值脱敏，用户变量由 Android Keystore 加密保存；临时变量只在当前会话生效。
- 输入框会实时提示已识别的变量及其作用域，普通正文中的同类文本不会被误处理。

## Codex Work

- 补齐 Codex Work 的四个可用模型，并统一为 Low、Medium、High、XHigh、Max 五档思考强度。
- 根据模型能力过滤不支持的档位；Spark 不再显示 Max，Core 与 Runner 也会拒绝无效组合。
- 优化手机端模型选择和会话状态呈现，减少配置与实际执行不一致的问题。

## 长对话压缩

- 自动压缩改为按完整请求 token 预算判断，在约 262k token 时创建上下文检查点，不再依赖消息条数。
- 手动压缩与自动压缩共用同一引擎，并提供 4k、8k、12k、16k 四档检查点预算。
- 稳定提示层计入总预算但不会进入摘要；近期完整对话继续保留，降低事实与指令在压缩中丢失的风险。
- 原始消息仍保存在会话中；编辑、删除或切换分支后旧检查点会自动失效，便于安全恢复和重新压缩。
