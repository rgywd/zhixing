# 知行 0.3.0

0.3.0 将 Work 从 Happy/自定义中继协议迁移到 Codex App Server 原生链路。手机通过 Tailscale WSS
直接连接开发机，Supervisor 只负责拉起进程、健康检查、仓库元数据和受控附件，不再代理或翻译聊天消息。

## Chat / Work 双模式

- 在原聊天侧栏中紧凑切换 Chat 与 Work；选择会被持久化，应用重启后仍回到上次模式。
- Chat 分组继续管理普通 AI 对话；Work 分组直接对应 Codex 仓库，并立即进入当前 Thread。
- 项目、连接与旧版历史管理收拢到现有设置页的 Work 卡片，不再维护独立设置入口。

## 原生聊天体验

- Work 直接复用知行现有聊天顶栏、时间线、输入框、Markdown、思考过程、工具卡、审批、语音、发送与停止行为。
- 模型和思考深度使用普通聊天的原生选择控件；Fast 与访问权限收拢到统一附件面板。
- 拍照、照片和文件上传复用同一附件流程；Skill、插件、App 与 `/new`、`/compact` 通过 `/` 补全选择。
- 新建 Work 对话直接创建 Codex Thread，不再先弹任务表单。

## 直连与可靠性

- 数据路径简化为 Android -> Tailscale WSS -> Codex App Server，VPS Relay 与 Agent 不再位于消息路径。
- 内置模型目录可离线乐观渲染；服务端目录刷新失败不会锁死模型与思考强度控件。
- 会话快照、实时事件、附件清单和恢复状态继续使用统一投影与缓存，断线重连后可继续当前 Thread。
- Supervisor 提供 App Server 生命周期、Tailscale HTTPS 探测、状态页与受控附件目录。

## 升级说明

- 可从 0.2.2 直接覆盖升级到 0.3.0，无需清除本地数据。
- 开发机需要安装本 Release 的 `zhixing-agent-0.3.0.tgz`，登录 Codex，并启用 Tailscale HTTPS。
- 0.2.x 的 Happy 凭据、缓存和服务端数据不会被删除，只作为只读迁移与回退资料保留。
