# 知行 0.4.16

0.4.16 增加本地渐进式记忆召回和健康统计，让 Work 与生活概览在手机端更清晰、更容易操作。

## 本地渐进式记忆召回

- 普通聊天的常驻记忆收敛为个人资料与偏好；人物、主题和领域文档在相关问题中按需查找并精确读取。
- 新增本地 `memory_find`、`memory_list` 与 `memory_read` 分层链路，支持中文分词、别名、目录浏览和分页，不依赖云端向量服务。
- 记忆文件统一使用可读的 Markdown 与 YAML 元数据，来源、别名、时间和作用域格式更稳定。
- 写入前继续核对用户原话与文档版本；凭据检测和日期格式处理更准确，减少合法内容被误拒绝。

## 健康统计与身体数据

- 统计页新增“健康”Tab，集中展示身体组成、生命体征、活动和睡眠数据，并合并 Lenovo Watch Pro 最近同步结果。
- 普通聊天可在用户明确提供数值时保存结构化健康记录；读取仍受“允许 AI 使用身体数据”开关控制。
- 健康数据必须绑定当前用户原话，不从照片、外观或模糊描述推断数值，也不提供诊断或风险评分。
- 生活概览新增今日步数、睡眠和心率速览卡，可直接进入健康统计页。

## Work 手机端体验

- 会话页统一用户消息、提问和汇报的边条式排版，减少状态色噪音，并收敛底部输入区层级。
- 模型、思考深度和速度改用分区操作表；仓库选择、附件和报告空态补齐更明确的交互提示。
- 首页与会话列表补充空态、错误重试、分组计数和两行元信息；消息支持点按打开操作表。
- “跳到最新”改为带未读角标的小型按钮，减少对正文的遮挡。

## 生活概览与服务收敛

- 右侧生活概览改为从屏幕右缘热区起手，降低与横向内容滑动的冲突；抽屉内问候、日期、事项和 Work 等待状态层级更清楚。
- 删除已经退役的套餐余量界面、Work Core 代理、CPA 采集器和 SSH 隧道配置；邮箱与飞书信息监控不受影响。

## 数据升级

- 数据库 schema 从 48 升级到 49，只新增结构化健康记录表及索引，不修改、删除或重建既有表。
- 现有聊天、记忆、Work 会话、Agenda、长期计划、月度收支、设备快照、知识库和用户文件会原样保留。
- 正式包名、签名和数据库身份保持不变，`versionCode` 递增到 45。
