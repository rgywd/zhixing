# 知行 0.4.17

0.4.17 让长对话和 Work 会话更稳定、更容易控制，并新增回答金句的精美分享卡片。

## 长对话与检索稳定性

- 普通聊天会在回复完成后静默准备上下文检查点，并在后续轮次按需启用，减少长对话临界点的等待。
- 会话级助手提示词与缓存前缀更加稳定；Claude 可在稳定边界复用提示缓存，动态时间与运行态信息仍保持实时。
- 模型上下文窗口支持逐模型覆盖，默认策略会分阶段准备和启用压缩，同时保留原始聊天记录与手动压缩入口。
- 同一轮中重复发起完全相同的只读检索时会复用首次成功结果，避免重复访问搜索服务和重复消耗 Token；失败重试与有副作用工具不受影响。

## Work 会话控制与快捷入口

- Codex Work 会话新增上下文占用圆环，可查看 Token 详情并执行原生 compact；Claude Code 支持本地 `/context` 与 `/compact`。
- 桌面新增“打开 Work”快捷入口，并按等待用户优先级展示活跃会话，点击可直达对应会话。
- Work 的 ask 通知可直接采用推荐方案；缺少推荐选项或请求已经落定时仍按原有安全与幂等边界处理。

## 金句分享卡片

- 长按框选回答文字后，原生菜单会追加“分享”，复制、全选、翻译、系统文字处理和整段回答导出保持不变。
- 可用暖纸或夜读主题分享图片，也可直接分享纯文字；较长选区仍保留文字分享能力。
- 卡片采用行书小字号排版，日期与正文同字号并附秒级时间戳，底部固定手写体“知行 · 知行合一”。

## 数据升级

- 数据库 schema 保持 49，不新增、删除或重建数据表。
- 现有聊天、记忆、Work 会话、Agenda、长期计划、月度收支、健康记录、设备快照、知识库和用户文件保持不变。
- 正式包名、签名和数据库身份保持不变，`versionCode` 递增到 46。
