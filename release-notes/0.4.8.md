# 知行 0.4.8

0.4.8 为 Work 手机工作台加入普通文件与压缩包附件，并修复多会话切换和长内容抽屉手势的体验问题。

## Work 文件附件

- Work 会话现在可发送常见文档、源码以及 ZIP、7z、GZip 压缩包；每条消息最多 4 个文件，单文件最多 10 MiB。
- 压缩包保持原文件交给 Codex 或 Claude Code，Agent 可按任务需要查看内容，不会在上传阶段自动解压。
- 普通文件由 Work Core 的持久化目录托管，数据库只保存相对存储位置与元数据；同时增加完整性校验、过期上传清理和任务临时文件清理，既有图片附件保持兼容。

## 多会话与生成

- 修复切回正在生成的会话时 UI 短暂空白的问题。此前从会话 A 切到 B 再切回 A 时，正在流式生成的 AI 回复会被数据库旧内容覆盖，导致切回后"啥也没有"、误以为生成中断；现在生成中保留内存态，切回即可看到已生成的回复。
- 生成任务跑在全局作用域并受前台服务保护，切换会话不会中断后台生成；多个会话可并行生成。

## 右侧抽屉

- 将右侧抽屉的手势排除区域扩展到所有可滚动的 Markdown 内容，避免在长回复上误触发抽屉滑动，滑动浏览更顺滑。
