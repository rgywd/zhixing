# 知行 0.3.8

0.3.8 将右侧生活概览的“套餐余量”从占位卡升级为真实数据，并修复右侧栏滑动入口与豆包搜索解析问题。

## 套餐余量

- 接入 Codex、Kimi、SuperGrok（xAI）等账号的真实套餐余量、时间窗和重置时间。
- 多账号按服务商聚合展示，但不会把不同类型或不同周期的额度错误相加。
- 暂不可用、采集失败、未接入和不支持查询都会明确显示，不会把未知余量伪装成 0。
- 手机端与 Work Core 都保留最后一次成功结果；弱网或监控服务暂时不可用时，会标记缓存或过期状态。

## 安全链路

- 套餐监控令牌只保存在自建 Work Core，不会写入 APK。
- Work Core 与 CPA Quota Monitor 之间使用用途受限的 SSH 加密隧道，不新增公开的监控端口。
- Android 仍只通过现有 HTTPS Work Core 接口获取经过校验的只读数据。

## 交互与兼容性修复

- 修复从聊天页向左滑动时右侧生活概览无法打开的问题；顶栏入口仍然保留。
- 修复豆包搜索在部分响应形态下无法正确解析结果的问题。
- 增加独立 staging 测试客户端和可驱动场景，正式版身份、升级地址与测试版继续隔离。

## 安装与升级

- GitHub Release 只提供一个 `zhixing-0.3.8-universal.apk`，同时覆盖 arm64-v8a 真机与 x86_64 测试环境。
- 可从 0.3.7 直接覆盖升级到 0.3.8；本版本不包含新的数据库迁移。
