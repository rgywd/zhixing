# 知行 0.4.18

0.4.18 集中更新模型推理档位与百炼模型的内置工具配置。

## 模型推理档位

- 普通 Chat 的推理滑杆统一为关闭、低度、中度、高度、超高与极致六档，移除容易产生歧义的自动档。
- OpenAI-compatible 请求会按端点和模型族映射实际推理参数，同时保留非 Chat 场景的自动预算语义。

## 百炼模型内置工具

- 国际版百炼为支持的模型增加联网搜索、网页正文抓取、文搜图与图搜图能力配置。
- 仅在启用百炼内置工具时切换到 Responses API；本地函数工具继续可用，搜索来源和图片结果会以结构化引用展示。
- 工具能力按模型实际支持范围开放，避免向不支持的模型发送无效参数。

## 配置升级

- 旧助手的普通 Chat 自动推理档会迁移为中度，其他已有模型与助手配置保持不变。
- 数据库 schema 保持 49，不新增、删除或重建数据表。
- 正式包名、签名和数据库身份保持不变，`versionCode` 递增到 47。
