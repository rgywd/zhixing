# 知行 0.4.1

0.4.1 完善 Work 手机会话中的提问闭环：即使用户暂时没有查看手机，Codex 也能按明确的推荐方案继续执行，
不再因等待回答而丢失决策或长期停滞。

## Work 提问与默认决策

- Codex 发起选择题时必须给出推荐答案；单选题始终只有一个明确推荐，多选题可给出多个推荐项。
- 用户在 180 秒内没有回答时，Work Core 自动采用推荐答案、记录决策来源并让当前任务继续运行。
- 超时后的迟到回答不会重复恢复任务；需要改变决定时，可直接在同一 Work 会话中发送补充消息。
- Work Core 重启后会收敛仍在等待的提问，采用推荐答案并恢复会话，不留下永久等待状态。

## 手机交互与通知

- 问题卡默认选中推荐项并显示“推荐”标记，可一键确认或改选。
- 卡片显示距离自动采用推荐方案的倒计时，落定后区分“已回答”和“已超时，采用推荐方案”。
- 提问通知按问题独立管理；问题落定后自动取消，并在截止前约一分钟补充一次临期提醒。

## 兼容性

- Work 协议主版本保持为 1，已有会话、消息、报告和账号配置继续保留。
- 0.4.1 发布前同步部署对应的 Work Core，并更新本机 Work Runner，使推荐答案与超时落定行为完整生效。
