# 知行 0.3.10

0.3.10 让 Work 会话的运行状态更可信，加入 Lenovo Watch Pro 只读同步，并把 GitHub Issue 操作
收敛到受控的本地 CLI 工具。

## Work 状态与时间线

- 会话页综合会话状态、开发机 Runner 租约和最后事件时间判断任务是否仍在运行。
- 正常运行时显示本轮开始时间和最近更新时间；开发机失联时明确降级为“任务状态待确认”，不再拿旧状态冒充在线。
- 运行事件按时间线展示；本轮结束显示“可继续”，不会误写成整个会话已经结束。
- 活跃会话会后台刷新开发机在线态；弱网刷新失败仍保留缓存、消息和输入能力。

## Lenovo Watch Pro

- 右侧生活概览支持显式配对 Lenovo Watch Pro，并以只读方式同步步数、睡眠、心率、血氧等已确认健康数据。
- 配对身份保存在 App 私有存储；关闭蓝牙或杀进程不会解绑，恢复后可按已保存设备自动重连。
- 长历史同步期间保存本地检查点，完成后推进增量游标，避免中断后仪表盘重新变空。
- 修正新版睡眠历史的总时长、深睡和 REM 统计，避免重复累加。
- 首版不提供解绑、重置、OTA 或文件传输等破坏性命令。

## 受控 GitHub Issue 工具

- 模型侧统一使用 `gh` 工具处理当前私有仓库的 Issue 查询和维护。
- 每次调用仍需用户确认；Token 只注入当前子进程，不进入命令行、普通 workspace shell 或 Rootfs 持久配置。
- 仅开放显式 Issue 子命令，并固定目标仓库，禁止 `gh api`、扩展、Secret、Variable 和跨仓操作。

## 开发与稳定性

- 修复 Windows 开发机缺少 `/bin/sh` 导致的 workspace 测试失败，自动使用 Git for Windows 的 POSIX shell。
- Rootfs 符号链接在支持的平台保持真实链接；Windows 缺少链接特权时，只对 rootfs 内已存在文件安全降级。
- workspace 的目录执行、stdin、输出截断和 rootfs 解压测试已在 Windows 与 Linux CI 通过。
