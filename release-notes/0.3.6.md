# 知行 0.3.6

0.3.6 重点改善聊天页双侧边栏操作，并补强 Work 首次启动失败后的恢复能力与多会话状态隔离。

## 聊天页与事项边栏

- 常规宽度下，事项、聊天选项和新建会话三个操作会直接显示在顶栏；只有紧凑宽度才收进更多菜单。
- 在对话页向左滑动可以打开右侧事项边栏，边栏展开后向右滑动即可关闭。
- 滑动需要满足方向与距离阈值，代码块、表格等内部横向滚动区域会优先处理自己的手势；按钮、遮罩、关闭键和系统返回仍可正常使用。

## Work 会话恢复与隔离

- 首次启动失败但尚未建立 Codex 会话时，恢复操作会使用历史消息和原附件重新创建启动命令。
- 附件下载支持有界重试，临时网络错误不再直接让首次会话失去恢复机会。
- 恢复命令补齐仓库、模型和思考强度快照，新版 Runner 可以继续恢复旧版失败会话。
- Work 会话页面按会话 ID 隔离 ViewModel，切换会话时不再串用输入状态或发送目标。

## 升级说明

- 可从 0.3.5 直接覆盖升级到 0.3.6，本版本不包含新的数据库迁移。
- 建议同时升级到本版本对应的 Work Core 与 Runner，以获得完整的首次失败恢复能力。
