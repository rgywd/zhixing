# 知行 v0.4.20

- Work 拆为独立应用，独立管理开发会话、通知和本地数据；Chat 保留原有聊天及生活概览设计。
- Work 设置支持从同签名的新版 Chat 一键导入 Core 连接、模型、语音、主题及仓库偏好。
- 修复通知授权状态在重新打开应用后识别不一致的问题。
- 保留 v0.4.19 的荣耀任意门、搜索、记忆和发布链路改进，不包含统一导航、悬浮球和切换背景实验。

## 安装与迁移

1. 先安装 `zhixing-0.4.20-universal.apk`，覆盖升级 Chat，保留原数据。
2. 安装 `zhixing-work-0.4.20-universal.apk`，两个应用可同时存在。
3. 打开 Work → 设置 → 一键导入，再单独开启 Work 的通知权限。

Work 历史由原 Core 同步。Chat 本地未发送的 Work 草稿不会迁移；Chat 没有配置 Core 时，可在 Work 手动连接。
Work 暂通过本发布页获取后续安装包。已验证本地构建、模拟器导入/加密保存/深链/权限持久性；真实 Core/Runner 任务链路仍需连接后验证。
