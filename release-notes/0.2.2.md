# 知行 0.2.2

这是 Codex 原生工作会话的完整交互版本。工作页不再只是任务监控入口，而是复用知行既有聊天体验，
直接继续开发机上的 Codex 项目与历史对话。

## 原生会话

- 复用现有输入框、附件预览、语音、Markdown、思考过程和工具卡渲染。
- 支持完整多轮历史，以及正文、思考、计划、命令、文件修改、MCP、网页搜索和协作任务的实时更新。
- 计划以结构化 `update_plan` 工具卡展示；历史快照与实时事件使用同一投影链路。
- 运行中可以继续补充要求，也可以单独停止；审批与交互请求支持允许、拒绝和取消。

## 模型与能力

- 模型、思考深度、Fast、权限配置、Skill、插件和 App 均来自开发机当前 Codex 动态目录。
- 显示服务端确认的实际模型、思考深度、权限、服务档位和上下文用量，模型重路由会同步更新。
- 支持发送图片和通用文件；上传回执、哈希、大小、TTL 与路径范围均由 Agent 校验。

## 历史与可靠性

- 大历史使用带 revision 与哈希的加密分块传输；缺块或旧 revision 不会覆盖手机上的可用历史。
- 修复 Windows 与 Linux 之间 Skill 路径语义漂移，开发机路径不再被中继或 Agent 主机错误改写。
- Room 数据库升级到 v31，并通过正式 `30 -> 31` 迁移保留 0.2.1 的项目、对话与设置。

## 验证

- Android 223 项、Agent 70 项、Relay 7 项自动化测试全部通过。
- Android 35 模拟器完成 Room 覆盖升级、浅色/深色、大字体、横屏和输入法场景验证。
- 四轮独立验收中，前两轮发现并推动修复真实缺口；最终两轮全部 P0 PASS，阻断项为零。

## 升级说明

- 手机端可从 0.2.1 直接覆盖升级到 0.2.2，无需清除应用数据。
- 开发机必须同步安装本 Release 中的 `zhixing-agent-0.2.2.tgz` 并重新启动 daemon。
- Relay Wire v1、恢复密钥、旧版 Happy 只读历史和本地整理偏好均保持兼容。
