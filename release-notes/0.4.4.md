# 知行 0.4.4

0.4.4 扩展了事项规划、手机 Work 和月度账本能力，并让“现在”面板、记忆维护和聊天交互更加稳定。

## 事项与“现在”

- 空会话首页会聚合值得注意的当前状态、待办和长期计划，帮助快速判断下一步。
- 长期计划支持阶段编辑、时间线和提醒，设备日历投影与提醒恢复更加可靠。
- 修复聊天页左右抽屉与横向表格的手势串扰，并新增可关闭的右栏打开手势。

## Work 与信息监控

- 手机 Work 支持创建和继续 Claude Code 会话，并可继承已配置的第三方 Claude API。
- 优化仓库选择体验，记住常用项目，减少每次创建会话时的重复选择。
- 增加邮件与飞书只读监控工具入口；配置配套服务后，可在聊天中查询统一的摘要事件。

## 月度账本

- AI 可汇总月度收支并保存到统计页，形成可持续查看的月度账本。
- 汇总成功后安全清理受管附件和 OCR 缓存，避免账单文件长期占用空间。

## 稳定性与数据安全

- 收紧自动画像与记忆边界，串行维护同一维度的画像，并补充可控遗忘能力。
- 强化数据库备份、恢复和升级契约，覆盖新增账本与 Work 数据。
- 将 Android Lint 纳入持续集成，补齐现有功能翻译，并修复多处生成、设置和界面状态问题。
