# 知行 0.3.2

0.3.2 新增豆包搜索，并允许一次联网搜索同时查询多个搜索源。多源结果会并发获取、交叉排列并按网址去重，降低单一来源缺失、偏差或暂时不可用对回答的影响。

## 豆包搜索

- 搜索服务设置中新增“豆包搜索”，填写 API Key 即可使用。
- 除 API Key 外，请求参数使用内置默认配置；返回数量沿用通用搜索设置。
- 搜索结果优先使用摘要，并兼容摘要缺失时的片段内容。

## 多搜索源

- Android 和 Web 对话页的搜索选择器支持同时勾选多个已配置搜索源。
- 一次 `search_web` 调用会并发请求全部启用来源；某个来源失败时，其余成功结果仍会返回，并标记失败的提供商。
- 不同来源的结果按位次交叉排列；相同网址会合并为一条，并保留所有返回该结果的搜索提供商标识。
- `scrape_web` 使用设置顺序中第一个已启用且支持网页抓取的提供商，工具说明会明确显示实际来源。

## 升级说明

- 可从 0.3.1 直接覆盖升级到 0.3.2。
- 原有单选搜索配置会自动迁移为对应搜索源的 ID；同时保留兼容索引，便于降级或回退多搜索功能。
- 至少需要保留一个启用的应用搜索源；模型内置搜索的开关逻辑不变。
