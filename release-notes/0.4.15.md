# 知行 0.4.15

0.4.15 让长期记忆在复杂对话中能够连续追踪相关信息，并让 Work 队列中的消息可以直接转为当前任务引导。

## 记忆连续读写

- 同一次普通聊天 Run 可以沿着直接相关的人物、主题和项目文档继续读取，不再被单次读取限制打断。
- 一轮对话中出现多类值得长期保留的信息时，可以按归属连续更新多份记忆文档。
- 再次修改同一份文档时会复用最新版本，继续保持乐观锁、用户原话来源和文档作用域保护。
- 记忆仍然按需调用；无关问题不读取，没有新信息时不写入。

## Work 队列转引导

- 待执行队列中的消息新增“引导当前任务”操作，可直接把文字和附件送入正在运行的 Codex turn。
- 转换同时校验队列 revision 和当前 active turn，避免编辑、派发或 turn 切换时把消息送错位置。
- Runner 接受后才把消息写入聊天历史；如果当前 turn 已结束或拒绝引导，消息和附件会恢复到原队列，不会丢失。
- 队列消息原本携带的下一轮思考深度和速度不会改变已经运行中的 turn。

## 数据升级

- 数据库 schema 保持 48，本版不新增数据迁移，也不改变正式包名、签名或数据库身份。
- 现有聊天、记忆、Work 会话、队列、附件、Agenda、长期计划和知识库数据会原样保留。
