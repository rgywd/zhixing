# 知行 0.4.13

0.4.13 让 Work 会话在任务运行中也能继续沟通，并修复正式版开启精确定位时可能发生的原生闪退。

## Work 实时沟通与队列

- 当前回合运行时，点按发送会把补充内容加入持久化 FIFO 队列，任务完成后按顺序自动继续。
- 长按发送可以直接引导正在运行的 Codex 回合，不必停止任务或等待下一轮。
- 队列默认折叠展示，可展开编辑或撤回尚未派发的内容；弱网、Core 或 Runner 重启后仍会保留。
- Work 会话页会显示当前活动回合和系统错误，停止、失败与正常完成后的队列行为更加明确。

## 模型、思考深度与速度

- 模型、思考深度和 Codex 速度合并为一个分层菜单，减少多处设置之间的不一致。
- Codex 支持“标准 / 快速”切换；只有 Runner 明确支持的模型才能启用快速模式。
- 新建 Codex 会话默认使用 `xhigh`，Claude Code 默认使用 `max`；已有会话和手动选择不会被覆盖。

## 定位稳定性

- 修复正式版经过 R8 压缩后，高德定位内部 JNI 类被裁剪，导致开启精确定位时触发原生闪退的问题。
- 保留必要的高德定位桥接类，不改变现有定位授权、坐标与隐私边界。

## 数据升级

- 数据库由 schema 46 升级到 48，为 Work 会话增加快速模式和活动回合状态。
- 现有聊天、Work 会话、运行时 session、Agenda、长期记忆和知识库数据会原样保留。
