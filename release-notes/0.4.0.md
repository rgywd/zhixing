# 知行 0.4.0

0.4.0 把右侧“现在”从设备数据仪表盘升级为日常助理，并增强 Chat 与 Work 在后台和长任务场景下的可靠性。

## 现在与我的状态

- 首屏以时段、日期、粗粒度位置为背景，优先给出综合状态、身体与环境解读及一条行动建议。
- 天气与状态每小时或在关键输入变化时刷新；位置只以行政区域级信息进入快速模型，不发送精确坐标。
- 身体数据进入 AI 上下文由独立设置控制；关闭后仍可在本机使用，但不会进入模型请求。
- 设备连接和同步入口迁移到“设置 → 我的设备”，已配对设备保持连接并按成功同步时间自动增量拉取。

## 我的事项

- 在简单待办之外增加长期计划和阶段节点，可表达“提前 15 天购票”等跨半月相对时间。
- 当前行动保持紧凑展示，完整计划、等待节点、未来安排和已完成内容进入独立事项页。
- 阶段提醒可跨重启重建，通知可直达对应计划；AI 创建和修改仍经过用户审批。
- 我的状态会同时理解简单待办和长期计划的当前阶段。

## 套餐余量

- 多额度渠道改为紧凑牌组，点击渠道后展开该渠道的全部账号和额度窗口。
- 周限额、五小时限额、代码审查及额外模型额度同时保留，不再用单条最低余量代替全貌。

## Chat 与 Work

- 普通 Chat 生成期间使用按运行计数的前台服务，切到后台后继续执行；取消、失败和完成会可靠释放服务。
- 生成中断时保留已有局部回复，通知可返回对应会话并取消生成。
- Work 会话首页和时间线采用统一状态语义，等待回答、运行、空闲和失败更容易区分。
- HTML 报告支持语义化排版、深色模式、分享、缩放与安全外链，服务端继续清洗不受信任内容。

## 数据与兼容性

- 数据库升级到 v39，新增长期计划表并保留既有待办与其他本地数据。
- Work Core 协议保持向后兼容；0.4.0 发布前同步部署新版服务。
