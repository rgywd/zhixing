# 知行 0.4.11

0.4.11 加强了 Work 会话、知识库助手和长期记忆的可控性，并修正套餐余量与聊天任务卡的显示问题。

## Work 与模型控制

- Work 会话现在可以在发送下一条消息时切换思考深度，新设置从该消息开始生效。
- 可选思考深度会随当前运行时和模型校验，避免提交设备不支持的组合。

## 知识库助手

- 助手可从知识库固定路径读取用户提示词，并在对话首条消息时保存不可变快照。
- 修改知识库提示词只影响之后开始的新对话，已有对话和分支不会被静默改写。

## 长期记忆

- 修复记忆写入缺少可信来源绑定时出现通用工具错误的问题，来源由应用根据当前用户消息安全绑定。
- 记忆写入校验失败后可以修正参数重试，只有成功写入或明确无需变更后才完成本轮收尾。

## 稳定性修复

- 套餐余量只显示当前仍有效的渠道，已删除、禁用或迁移的旧渠道不会继续占位。
- 上游暂时不可用时保留最近一次可信余量，不再把未知状态误显示为零。
- 从聊天发起的任务不再在来源对话中显示指向自身的任务卡。

## 数据升级

- 数据库由 schema 44 升级到 45，为对话增加用户提示词快照；现有聊天、事项、记忆和工作区数据会原样保留。
