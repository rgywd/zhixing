# 知行 0.2.0

这次更新把“工作”模块升级为面向 Codex 项目与任务的原生移动工作台。手机不再依赖 Happy 网页或“最近 15 分钟活跃会话”，可以按项目查看本机 Codex 已落盘的历史任务，并在原任务上继续工作。

## 主要变化

- 项目优先：首页按开发机与项目目录组织全部 Codex 历史任务，支持搜索、继续、新建、归档与删除。
- 原生任务页：消息增量、工具活动、审批、补充要求、打断与完成状态直接显示在知行 Android 界面。
- Codex App Server：开发机 Agent 通过官方 App Server 协议读取 Thread，并保持项目、历史和运行时状态一致。
- Wire v1：使用自有端到端加密协议与盲中继；手机不直连开发机，中继不能读取任务正文。
- 自托管闭环：中继具备健康检查、持久化、备份和恢复流程；Agent 随 Release 提供独立安装包。
- 平滑迁移：0.1.13 的 Happy 凭据与历史不被删除，设置中保留只读入口和明确回滚路径。

## 升级说明

- 可从应用内更新直接安装 0.2.0；Android `versionCode` 已递增，签名保持不变。
- 开发机请安装本 Release 的 `zhixing-agent-0.2.0.tgz`，执行 `zhixing-agent login` 后启动 `zhixing-agent daemon`。
- 若新链路出现阻断，可按 `docs/zhixing/CODEX_020_ROLLBACK.md` 回到 0.1.13；旧 Happy 数据和新 Wire 数据互不覆盖。

## 当前边界

- 0.2.0 只开放 Codex；Claude Code 通道冻结。
- Codex Desktop 私有运行中任务无法被外部 App Server 实时接管；已落盘任务可在手机端查看和继续。
