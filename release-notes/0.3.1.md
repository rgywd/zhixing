# 知行 0.3.1

0.3.1 补齐了 Work Phone-line 的日常使用闭环：手机可以把图片和文件交给开发机，Codex 会主动汇报关键进度，任务在后台运行时由状态栏持续跟踪；完成后还可以归档，并在需要时恢复原会话继续工作。

## 附件与仓库目录

- Work 会话支持从手机选择图片和文件，附件由 Core 持久化后交给开发机 Runner，不需要让手机直接访问仓库或开发机端口。
- 仓库目录由开发机白名单配置同步到手机，新建任务时可从可用仓库中选择，不再把任意本机路径暴露给移动端。
- 附件发送、下载和 Runner 消费均纳入 Phone-line 契约，并补充了 Core 与 Runner 回归测试。

## 主动汇报与关键提问

- 仅由知行手机发起的 Codex 会话会获得轻量 Phone-line 指令，桌面端普通 Codex 会话不受影响。
- Codex 可以通过 `report`、`ask`、`report_html` 主动汇报进度、向用户提问或交付长报告。
- 任务结束时会补交终态；短暂断网、进程换代或恢复执行时仍可沿用原会话状态。

## 状态栏跟踪与提醒

- 未归档且处于排队、运行或等待用户状态的任务，会在 Android 状态栏保持低打扰的前台跟踪通知。
- 完成、失败、即时汇报、HTML 报告和提问等关键节点会单独提醒；提问使用更醒目的高优先级通知。
- 点击通知可直接进入对应 Work 会话。Android 13 及以上首次使用时需要授予通知权限。
- 通知游标与消息同步游标分离，降低事件已经同步但关键提醒静默丢失的风险。

## 会话归档与恢复

- Work 首页可以在当前会话和已归档会话之间切换。
- 已结束或空闲的会话可归档；正在排队、执行或等待回答的会话不会被误归档。
- 恢复会话时保留原 Codex 会话 ID、全部事件和上下文；可继续执行的会话会从原上下文接着工作。
- 已归档会话保持只读，恢复后才能继续发送消息。

## 升级说明

- 可从 0.3.0 直接覆盖升级到 0.3.1，数据库会自动升级到 Room v34。
- 断开 Work Core 会停止后台跟踪并清理通知状态；重新配置 Core 后会恢复现有活动任务的跟踪。
- 普通聊天、助手、知识库和提供商设置不受本次升级影响。
