# 知行 0.3.7

0.3.7 上线右侧生活概览的第一版框架，并将 Android 安装包收敛为单一 Universal APK，方便先在真机上确认整体布局与交互，再逐项接入真实数据。

## 右侧生活概览

- 原事项抽屉升级为一条纵向生活概览，从上到下依次展示“我的状态”“我的事项”和“套餐余量”。
- 状态区采用步数主卡与双列指标卡布局，覆盖睡眠、心率、卡路里、运动锻炼、血氧和活动小时等位置。
- 事项区保留紧凑摘要，套餐区预留 Codex、Kimi 与 SuperGrok 的余量卡片。
- 继续支持从聊天页向左滑动打开、向右滑动关闭右侧栏，也可使用顶栏入口和关闭按钮。

## 当前数据边界

- 健康状态仍是布局预览，页面会明确标注设备未连接，不会把示例数字伪装成实时数据。
- 套餐余量仍标注为待接入，后续将按已经准备好的接口逐项替换为真实数据。

## 安装包与升级

- GitHub Release 从本版本起只提供一个 `zhixing-0.3.7-universal.apk`，不再单独发布 ARM64 与 x86_64 安装包。
- Universal APK 内仍同时包含 arm64-v8a 与 x86_64，可覆盖真机和测试模拟器。
- 可从 0.3.6 直接覆盖升级到 0.3.7，本版本不包含新的数据库迁移。
