# 知行 0.2.1

这是 0.2.0 Codex 原生工作模块的关键热修复。

## 修复

- 修复 Windows 开发机 Agent 在首次目录扫描结束后自动退出的问题。
- Codex Wire 的目录同步与运行时轮询现在会持续常驻，直到用户明确停止 Agent 或电脑关机。
- 新增生命周期回归测试，防止服务定时器再次被错误地从 Node 事件循环解除引用。
- 修复完整 Codex 历史直接堆满工作主页的问题：主页只保留置顶项目和最多 8 个最近可工作项目。
- 只含归档任务或开发机目录已经删除的历史项目会自动收进“管理全部”，仍可搜索和查看，不会丢数据。

## 整理能力

- 支持项目置顶、从主页隐藏和恢复；这些操作只影响手机展示，不会删除开发机目录或 Codex 历史。
- 支持把高价值对话设为“重点”；归档对话默认只在归档筛选和重点区出现。
- 项目与对话整理偏好独立持久化，后续目录同步不会冲掉用户的整理结果。

## 升级说明

- 手机端可直接从 0.2.0 覆盖升级到 0.2.1。
- 开发机必须同步升级本 Release 中的 `zhixing-agent-0.2.1.tgz`，然后重新启动 `zhixing-agent daemon`。
- App 会自动完成 Room v29 数据库迁移；Relay 协议、恢复密钥、项目缓存和旧版 Happy 只读数据无需手动迁移。
