# 长期用户画像 V2（已退役）

状态：已于 2026-08-11 从运行时移除。

旧版本曾通过 WorkManager、跨聊天证据阈值和时间窗口静默合成 PROFILE/OBSERVATION。该机制不再注册模型
维护服务，相关配置也不再读取或写入。应用升级时只取消旧版本可能遗留的 WorkManager 唯一任务；同名 Worker
仅保留一个立即成功的兼容壳，防止升级竞态触发旧任务时出现类加载失败。两者都不调用模型、不读取聊天、不写入
记忆，也不调度或重试。

旧 `MemoryEntity` 表暂留一版用于回滚与审计；数据库 43→44 会把非删除记录转存为只读
`/archive/legacy-memory*.md`，不会注入提示词，也不会冒充用户陈述。

现行机制以每次 chat Run 的可见工具调用为边界：模型在最终回复前主动评估当前 USER 消息，只把用户明确说出的
长期事实写入记忆文档。完整契约见 [记忆文档与历史对话检索 V3](MEMORY_SYSTEM.md)。
