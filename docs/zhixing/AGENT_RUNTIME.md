# 自主配置与子智能体运行契约

状态：受管文件入口已实现，DeepSeek 消息续接与操作回执修正，2026-09-21。

## 配置与权限

Assistant 是智能体的持久配置，Settings DataStore 是唯一配置事实来源。设置页和聊天工具共享写入入口。
配置修改在串行事务内读取最新状态；模型修改使用配置版本检查，省略字段不变。旧 UI 快照只合并实际改动，
同一字段冲突拒绝覆盖并提示重试。恢复操作生成新版本，不回退版本号。每个助手保留上一版配置供恢复。

主智能体复用 `workspace_read_file`、`workspace_write_file`、`workspace_edit_file` 操作受管文件目录，
无需创建 Workspace 或安装 Rootfs。模型侧不注册 `agent_catalog`、`agent_config`、`agent_skill` 或
`agent_apply_config`；运行操作仍使用 `agent_run`。

这些路径是受管虚拟文件，不是 Rootfs 中的实体镜像。Assistant 仍通过 SettingsStore/DataStore 单一事务
持久化，因此设置页、聊天和现有配置备份始终使用同一份数据，不需要额外文件同步或旧配置迁移。
SKILL.md 则映射既有 SkillManager 的实体文件。Shell 不挂载这些配置路径。

| 路径 | 用途 |
| --- | --- |
| `/agents` | 读取目录，列出自己及所管理助手的 UUID 和名称 |
| `/agents/self/config.json` | 当前助手的可编辑配置及只读身份、版本字段 |
| `/agents/self/AGENT.md` | 当前助手的用户提示词 |
| `/agents/<UUID>/config.json` | 已有助手配置；向新的 UUID 路径写入 name 等配置可创建子助手 |
| `/agents/<UUID>/AGENT.md` | 子助手提示词；先创建 config.json |
| `/agents/<UUID>/previous.json` | 上一版配置的只读安全视图；也可通过设置页恢复上一版 |
| `/agents/resources.json` | 已配置模型、工作区、技能、能力和已启用 MCP 的标识 |
| `/skills`、`/skills/<name>/SKILL.md` | 共享技能目录与说明文档 |

写入已有文件前必须读取；write 使用读取版本或显式 if_revision，edit 在新读取上进行精确替换并校验版本。
创建子助手 config.json 后，AGENT.md 已自动存在且为空，仍须先读再写。所有配置文件共享助手版本；
修改一个文件后，写另一个文件前须重新读取。未读取返回 READ_BEFORE_WRITE，旧版本返回 REVISION_CONFLICT，
两者均提示重新读取并保留无关改动。文件写入回执只在顶层给出生效范围，避免内部事务回执产生歧义。
写入自己的 AGENT.md 返回 current_conversation_next_turn，明确不需要新建对话；子助手 AGENT.md 返回
new_conversations，普通 config.json 返回 next_run。
工具说明要求局部修改优先精确替换，追加规则时逐字保留原提示词，改名只修改配置 name；
未明确要求时不连带重写提示词中的自称。这是模型操作指引，存储层仍允许用户要求的完整提示词重写。
未知字段、路径穿越、越权访问、冲突和无效资源标识均拒绝提交。配置 JSON 中省略的字段保留，数组替换，
身份和版本字段只读。目录仅显示可管理助手；不会返回 Provider 密钥、MCP headers 或完整 Settings。
模型选择复用已有连接，新增凭据和系统权限仍通过设置完成。技能写入仅支持 SKILL.md，不执行安装脚本。

旧助手的空能力配置保留已有行为；显式能力集合是工具白名单，未知工具不自动进入。新建子智能体默认为空集合，
只保留时间和业务问答。配置管理权与业务执行能力分开；主智能体可分配已配置连接的能力而不加载该业务工具。
子智能体不获得管理工具，不进行递归委派。MCP 工具选择绑定本次运行助手，不读取界面当前选择。
每次工具执行重新检查最新启停与能力配置，MCP 调用还核对最新服务器和工具选择。

设置页提供启停、能力配置与恢复上一版。普通配置作用于下一次运行；已开始的运行使用固定的配置和工具集合，
权限撤销立即阻止后续工具调用。写入自己的 AGENT.md 同时刷新当前对话的用户提示词快照，下次运行采用新提示词；已开始的运行保持原快照。其他已有对话和已开始的子任务保持各自快照，新对话采用最新提示词。

## 委派

`agent_run` 提供 start/list/get/wait/answer/continue/retry/stop。子任务用独立 Conversation 保存消息，复用
ChatService、GenerationHandler、Provider、前台服务和消息界面。主智能体只交付明确的指令；仅在指定时转交
最近用户消息的图片和文档，不复制全部历史。附件由现有持久会话引用检查保护。

Room `agent_runs` 保存父会话、请求标识、子会话、执行配置快照、状态和版本。普通任务卡是展示投影，不能代替
此运行记录。相同父会话与 request_id 的 start 只创建一次；接续通过版本检查和最近命令标识避免重复提交。
answer/continue/retry 都必须携带 run_id、if_revision 和新的 request_id；answer 另需 question_id 与用户回答
instruction，continue 另需后续任务 instruction。WAITING_FOR_INPUT 只能 answer，COMPLETED 才可 continue，
FAILED/INTERRUPTED/STOPPED 才可 retry。缺版本、旧版本或错误状态返回明确错误及当前 revision、questions、
next_action 和 required_fields；不代替模型自动重试，不跳过版本检查。next_action 表示对应状态支持的后续操作，
任务完成后仅在用户需要继续时调用 continue。
单个父会话最多四个执行中的子任务，单个主智能体最多管理 32 个子智能体。

start/answer/continue/retry/wait 最多等待 45 秒，返回运行状态；未结束时主智能体应继续 wait，不能宣称完成。
COMPLETED 表示本轮模型执行正常结束，不替代业务结果验收；主智能体仍须检查返回内容中的失败、缺失信息和外部操作回执。
子智能体 ask_user 返回问题标识，主智能体在来源聊天询问用户，再将回答绑定到原问题继续运行。子结果是任务数据，
不具备修改主智能体配置或内部指令的权限。调用方只能读取、接续或停止当前父会话的子任务。

子任务离开前台仍由独立生成租约保护；主会话新消息取消旧主生成时，子会话任务不因此被取消。
应用重启将遗留 RUNNING 标记为 INTERRUPTED；用户确认需要继续后可显式 retry，不自动重放不确定的外部写入。
停止只取消后续执行，不撤销已发生的副作用。会话仍可从对应助手的历史列表查看。

## 本轮范围与入口

用户可以在聊天中要求「创建一个研究助手，只给搜索和技能能力」「把该助手的模型换为已连接模型」
「修改你的提示词，并应用到当前对话的下次运行」「让研究助手处理这张图片，完成后汇报」。
主智能体先读文件目录取得实际标识，再编辑配置或委派任务；设置页可检查并调整同一份配置。

本轮复用 Assistant、SettingsStore、SkillManager 和 ChatService，不引入第二套模型客户端。
不包含定时后台调度、递归多级委派、安装外部插件或自动申请 Android 权限。进程重启后的外部操作不会自动重放。
